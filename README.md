# Finora multipage
Original React/Vite financial information portal inspired by the general information architecture of KNfins, with separate routes for topic pages and articles.

Run:
npm install
npm run dev

Routes:
/
 /credit-cards
 /loans
 /financial-guides
 /news
 /about
 /article/<slug>

The disclosure language is newly written and reflects that the site is advertising-supported and may receive referral/affiliate compensation.
